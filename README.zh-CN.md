# 墨稿 Mogao Content Studio

[English](README.md) | 简体中文

把 Obsidian 笔记排成公众号、知乎、小红书和 X 内容。内置六套模板，也可以粘贴文章链接，提取版式并保存为自己的模板。

**当前版本：Obsidian 插件 0.1.16，配套浏览器助手 0.3.7，桌面预览版。** 转换在本地完成；保留原文内容，提供平台排版与分段，无需模型 API，也不自动改写或自动发表。

## 可以做什么

| 平台 | 输出 |
| --- | --- |
| 公众号 | 图片实际嵌入的 Word 图文、富文本、HTML、Markdown 和参考链接 |
| 知乎 | 富文本与 Markdown，保留标题、引用、列表、代码、表格和来源链接 |
| 小红书 | 长文图文正文、逐张复制原图、批量原图、1080 × 1440 PNG 图文卡片，按实际高度分页；提示文案和标题长度 |
| X | 富文本长文、按 280 加权字符拆分的串文；可逐条复制或导出独立 TXT |

内置模板：**墨白、朱砂、青竹、蓝图、奶油手记、黑金刊物**。模板可以调整字号和主题色、另存、导入导出 JSON。六套样式均可用于四个平台。

## 安装 Obsidian 插件

1. 在 [GitHub Releases](https://github.com/AI-Scarlett/obsidian-content-studio/releases/latest) 下载 `main.js`、`manifest.json`、`styles.css`。
2. 在 Vault 中创建 `.obsidian/plugins/content-studio/`，把三个文件放入其中。
3. 在 Obsidian 的 **设置 → 第三方插件** 中启用「Mogao Content Studio」。
4. 打开一篇笔记，点击左侧报纸图标；也可执行命令 **Mogao Content Studio：排版当前笔记**，或右键笔记选择 **用墨稿排版**。

若将来更新插件，替换 `main.js`、`manifest.json`、`styles.css` 即可，保留该插件的 `data.json`，其中存储你的模板和设置。

## 安装浏览器助手

浏览器助手负责把墨稿中的标题、正文和图片交给已经打开的平台编辑器。它目前不是 Chrome 应用商店扩展，需要通过“加载已解压的扩展程序”安装一次。

推荐在 Obsidian 墨稿中点击发布按钮；如果助手未安装，墨稿会打开安装引导并提供配套下载。也可以从 GitHub 获取：

1. 打开仓库的 [Actions](https://github.com/AI-Scarlett/obsidian-content-studio/actions) 页面，进入最新成功的 **Verify plugin** 或 **Release plugin** 运行。
2. 在页面底部 **Artifacts** 下载 `content-studio-package`（验证构建）或 `content-studio-0.1.16-package`（Release 构建），解压后找到 `mogao-browser-extension-0.3.7-preview.zip`。
3. 再解压这个浏览器助手 ZIP。在 Chrome 地址栏打开 `chrome://extensions`（Edge 使用 `edge://extensions`），打开右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择解压后的 `mogao-browser-extension` 文件夹。不要选择 ZIP 文件本身。
5. 在扩展卡片确认版本为 **0.3.7**。首次点击墨稿图标时，浏览器可能询问是否打开 Obsidian，请允许。

更新助手时，把新版本文件放回原来的扩展文件夹，然后在扩展管理页点击该卡片的 **重新加载**，确认仍显示 0.3.7。更新后不需要重新导入笔记，也不需要在平台编辑器里手动选图片。

浏览器助手只在你从墨稿点击发布后处理本次稿件，使用当前浏览器会话登录平台；没有全站读取 Vault、系统剪贴板或 Cookie 导出权限。登录和平台最终发表仍由你完成。完整权限、失败保护和当前限制见 [浏览器助手说明](browser-extension/README.md)。

## 日常使用

1. 选择笔记或读取当前笔记。也可以在工作台中直接粘贴 Markdown。
2. 工作台默认提供大幅正文编辑区；点击 **预览** 查看排版，宽窗口可用 **对照** 左右查看。**模板与样式** 抽屉内调整模板、字号、主题色或学习新模板。编辑只影响排版稿。
3. 在墨稿选择公众号、小红书、知乎或 X，点击对应的发布按钮。浏览器助手会自动接收当前排版稿并打开平台；如果尚未登录，请完成登录，随后同步标题、正文和图片。
4. 小红书和 X 会直接显示 **发布长文**、**发布图文** 两个按钮，不需要先选择模式。图文发布会按笔记顺序上传图片；X 的字数限制交给 X 处理。
5. 未安装助手时进入安装引导，可按上面的 GitHub 步骤安装。日常发布不用导出、选文件或再次点击导入。
6. 同步结束后在平台检查图文和保存状态，再自行确认发表。平台适配仍为预览版，真实账号的完整多图验收边界见 [安装及支持范围](browser-extension/README.md)。

**复制标题 / 复制图文正文** 仍分开提供。完整内容包、Word、原图和卡片导出放在辅助工具里，用于备份或其他场景。X 新增 **发布到 X 长文**，同步到 X Articles；账号须有长文权限。普通串文继续提供逐条复制。

内容包默认保存在 Vault 的 `墨稿导出/`；每次新建独立目录，不覆盖旧稿。可以在插件设置中修改导出目录。

每个内容包包含 `article.html`、`article.md`、`title.txt`、`caption.txt`、`template.json` 和 `manifest.json`。已经载入的图片会单独保存，并重写 Markdown 中的对应引用；HTML 中的图片以数据形式嵌入。小红书另有 `card-01.png` 等卡片，X 另有 `thread-01.txt` 等串文。

原笔记、日记和其他插件的设置不会被工作台改写。临时排版稿保存在当前打开的工作台中；关闭前请导出需要保留的修改。

## 用链接学习模板

点击 **链接学模板**，粘贴公开的公众号或网页文章链接。墨稿会读取页面和最多三份外部样式文件，提取：

- 正文的字体、字号、行距与颜色；
- 标题的颜色、边线、底色和留白；
- 引用、强调、列表、代码等元素的可用样式。

读取时自动跳过页面脚本、内嵌图片数据和其他媒体；不下载参考文章的图片。提取后用你自己的草稿预览，图片统一显示占位符，原笔记和发布用的图片不变。填写名称，再点击 **保存到模板库**。

链接读取和粘贴 HTML 都支持最多 20 MB 原始页面，在精简后保留最多 3 MB 的正文与样式；超限会说明是哪一部分过大。模板保存来源链接、导入时间和提取说明，不复制原文章正文或图片。

这是静态样式学习：能读取的样式会被映射到笔记的标题、正文和引用等元素。依赖脚本、外部字体、动画或复杂嵌套布局的文章，不能保证逐像素复刻；请在预览中检查后再保存。

0.1.16 起，按内层文字与外层段落/容器共同采样，保留正文主字号、字间距、首行缩进、空行间距、标题的前景与底色，以及整篇背景和边框。学习模板不再混入内置模板的装饰。保存前可切换 **样式示例** 和 **当前稿件** 检查效果；样式属性数量不代表还原程度。已保存的模板不会自动重写，请重新提取链接后另存。图片内的装饰、条件样式、多栏和复杂图形仍需对照调整。

遇到登录、验证或读取失败，可以使用 **粘贴 HTML** 导入含样式的正文 HTML。空页面、验证页或没有足够样式的页面会提示失败。导入后的模板也可以再手动微调。后续拿到具体参考文章时，应使用该链接做一次实际效果验收。

## 图片与平台差异

- 支持 Vault 中的 PNG、JPEG、GIF、WebP、AVIF 图片和 `![[附件]]` 写法；内部笔记链接保留显示文字。
- 读取笔记时自动载入本地附件和外链图片，保留正文中的位置及顺序。工作台显示已载入数量；编辑正文后会补载新图片。每篇最多 40 张不同图片，每张不超过 8 MB，最多同时下载 3 张。
- 复制富文本和保存内容包前会再次检查图片；有缺图时暂停操作并列出具体来源。点击 **重新载入图片** 可重试。小红书长文也复制富文本；只有 X 串文保留纯文字复制。
- 未找到或不支持的附件会显示占位和明确提示；SVG、PDF、音视频与 Obsidian 插件动态输出暂不作为图片导出。
- 小红书卡片遇到一页放不下的复杂表格或图片会提示调整；长段落会自动拆页，标题会尽量与下文一起分页。
- 富文本剪贴板和 HTML 中的内嵌图片可能被公众号、知乎过滤，复制成功不代表平台已经上传图片。**复制这张图** 与 **复制卡片** 单独写入 PNG 图片数据，适用于支持图片粘贴的位置；也可用 Word 或批量图片导出。点击“发布到平台”才会把这一篇稿件及图片交给对应平台；登录与最终发表由用户完成。
- 图文复制先写入 HTML 和纯文本，失败时兼容原生选区复制。单图复制支持 PNG、JPEG、WebP、AVIF、GIF（静态画面），超过 4,000 万像素时要求缩小；复制按钮不会混入正文或卡片。
- Word 输出使用原生文档结构和媒体文件，保留段落、图片位置、基础强调、列表、表格与链接。WebP、AVIF、GIF 会转成 PNG（GIF 为静态帧）；大图最长边缩至 2000 px。复杂模板背景和装饰不转换，浅色文字适配为白纸上可读的深色。
- 每份平台导出含 `title.txt`、`body.txt` 和操作说明；完整内容包的 `caption.txt` 也只含正文。标题始终可独立复制。


## 开发与验证

```bash
npm ci
npm run verify
npm run verify:extension
npm run package
```

`verify` 包含官方 Obsidian ESLint（不允许警告）、CSS 兼容检查、类型检查和 114 项测试。`verify:extension` 另含 75 项浏览器投递测试，使用真实 Tiptap / Draft.js 文档模型与离线公众号接口约定；不等于真实平台验收。开发用浏览器演示已从插件源码移出；请在 Obsidian 内验证真实笔记库操作。

0.1.2 起，GitHub Actions 从版本标签构建插件，并为三个 Release 文件生成来源证明。Release 只附带 Obsidian 支持的三个文件；ZIP 和校验和保存在 Actions 构建产物，也可用 `npm run package` 本地生成。下载后可运行 `gh attestation verify main.js --repo AI-Scarlett/obsidian-content-studio` 验证来源；`styles.css` 和 `manifest.json` 同理。

源码入口：`src/main.ts`；工作台：`src/ui/studio.ts`；平台渲染、模板、分页、下载逻辑：`src/core/`。

完整范围与验收记录见 [docs/verification.md](docs/verification.md)，数据与网络说明见 [docs/privacy.md](docs/privacy.md)。

## 网络与隐私

选择或读取含外链图片的笔记、编辑正文增加外链图片、重试图片时，会访问这些图片 URL。链接学模板会访问所填文章和最多三份样式文件。不携带浏览器 Cookie 或账号凭据，也不把整篇笔记发送给模型服务。图片 URL 的路径、查询参数会发送给该 URL 的服务方。遇到 TUN 虚拟 IP 时，使用 Cloudflare DNS-over-HTTPS 仅查询目标域名。无遥测、后台同步或自动发布，详见 [数据与网络](docs/privacy.md)。

## 审核中的行为提示

“Vault Enumeration”对应用户打开笔记选择器时列出 Markdown 笔记路径，供搜索选择；不批量读取正文，也不发送路径列表。启动插件、读取当前笔记不会遍历整个库。“Clipboard Access”仅对应点击复制按钮后的写入，插件不读取、监听或上传系统剪贴板。这两个必要能力可能继续显示在审核行为说明中。详细处理见 [审核说明](docs/review-response.md)。

## 浏览器发布助手（预览版）

在墨稿内发起发布，Chrome / Edge 扩展自动打开对应平台并同步当前稿件。未安装时进入安装引导；未登录时等待登录。[安装与限制说明](browser-extension/README.md)。完整扩展在真实平台的验收仍未完成。

点击浏览器工具栏的 **墨稿图标**，会请求打开 Obsidian 和墨稿工作台。已有工作台保留正在编辑的稿件；新开工作台读取当前笔记。首次可能需要确认“打开 Obsidian”，上次使用的仓库需启用墨稿。在待接收稿件的连接页点击图标，仍会继续该次同步。

0.1.16 配套浏览器助手 0.3.7。助手已运行 0.3.7 时，本次学模板修复无需重新加载助手；从更早版本升级助手时，替换文件后在扩展管理页重新加载一次。从 0.3.0 更新没有新增网站权限。以后每篇稿件都从墨稿直接发起，无需选文件。公众号上传素材后创建草稿并打开返回的编辑地址；其他三平台使用各自编辑器的原生上传和文档模型。公众号保留模板样式；知乎、小红书和 X 以平台支持的标题、强调、引用、列表等结构为准。参见 [本版变更](docs/releases/0.1.16.md)。


## 普通图文笔记和帖子

选择“小红书”或“X”后，底部直接显示 **发布长文** 和 **发布图文** 两个按钮。点击对应按钮即可打开浏览器并同步，不用先选择发布类型。图文话题可在按钮上方编辑。

小红书会按笔记顺序上传图片，填写标题、正文，并从原生候选列表选择话题。文末单独一行的 `#话题` 会自动出现在可编辑的话题栏，切换笔记时重新读取。支持 1–18 张图、20 字标题、正文含话题 1,000 字；单次最多 10 个话题，平台对个别账号的更低限制会显示为待处理提示。

X 普通图文帖会将标题放在首行，随后填写正文、话题并上传最多 4 张附件。图片由 X 统一显示在帖子附件区域，不能像 Articles 那样放在正文段落之间。墨稿完整传递文案，字数和账号权限由 X 自己处理。不会自动截断、拆帖或丢图。

新模式支持 PNG/JPEG/WebP；X 单图上限 5 MB，小红书本工具上限 8 MB。平台最终发表始终由你操作。墨稿为 0.1.16，助手为 0.3.7；助手已经是此版本时无需重新加载。真实账号的多图上传尚待验收，详见 [本版说明](docs/releases/0.1.16.md)。
