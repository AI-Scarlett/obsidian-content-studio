# 数据与网络

笔记转换、预览、模板保存、复制和内容包生成都在本机完成。没有模型服务、遥测、自动发布、后台轮询或账号登录流程。

插件的 `data.json` 保存所选平台、模板、导出目录以及自定义模板。模板只包含受约束的样式值与来源信息；原笔记正文不会上传或写进模板。导出内容包包含正文和原笔记的相对路径，应按你自己的稿件资料管理。

点击链接学习时请求文章页面及最多三份外部样式。选择或读取笔记、编辑正文新增图片、重试图片，以及复制或导出前补查缺图时，会下载正文中引用的外链图片；图片源站会接收到该图片 URL 的路径、查询参数和普通请求元数据。已载入图片仅在当前工作台内缓存，关闭后释放。请求不携带浏览器 Cookie、平台登录信息或原笔记内容，也不执行页面脚本。网页的标题只用于建议模板名称，不是可执行指令。

下载器校验协议、端口、域名解析与每次重定向，限制响应时间与解压后的大小，并将连接固定到已验证的公网地址。遇到 TUN 代理返回 `198.18.0.0/15` 虚拟地址时，会通过 Cloudflare 的 DNS-over-HTTPS 查询该目标域名的真实公网地址；该查询只发送域名，不发送笔记、文章正文或 URL 查询参数。仍无法确认公网地址时会停止读取，不把虚拟或内网地址加入允许列表。

页面 HTML、CSS 和用户导入的 JSON 被当作不可信输入。导出只使用允许的样式和 HTML 标签；CSS 中的网络加载、定位、脚本表达式等不会成为模板规则。

浏览器预览服务仅监听 `127.0.0.1:39271`。页面使用本浏览器的 localStorage 保存示例模板；预览下载接口要求同源请求。结束开发预览后，可以在启动终端按 Ctrl+C 关闭服务。
