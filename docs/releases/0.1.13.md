# Mogao Content Studio 0.1.13 / browser assistant 0.3.6 preview

X and Xiaohongshu now have separate article and normal-photo-post modes. The Studio mode selector remembers each platform's preference; its compact topic field extracts trailing hashtags and resets when a different note is loaded. Post preview shows plain caption text and the ordered image attachments. No per-draft file export, file selection or manual image clipboard step is needed.

X opens `/compose/post`, writes the title on the first line with the caption and hashtags through native Draft.js state, and adds each image to that dialog's uploader. Xiaohongshu opens `target=image`, uploads images first to reveal its caption editor, fills the separate title and native Tiptap body, and selects exact topic names from the site's native suggestions. Native topic IDs must be present after selection. No automatic publication is added.

Images retain their occurrence order, including repeated source files. Normal post limits are checked before opening the destination: X 4 photos and 280 weighted characters; Xiaohongshu 1–18 photos, 20-character title, 1,000-character caption including topics. Up to 10 Xiaohongshu topics are supported, with any lower account limit left to the native editor and reported as a failure. PNG/JPEG/WebP are supported, up to 5 MB per photo on X and 8 MB in this tool on Xiaohongshu. Over-limit content is never silently truncated or sliced. Links remain in the plain-text caption.

The adapter stops on existing text or attachments, native upload failure, extra images, changed prior image order, missing topic selection, changed caption or cancellation. It never retries a partial upload or clicks Post/Publish. X attachments use the platform's layout and are not inserted between paragraphs. X's readiness check is limited to attachment previews and the native submit control; it is not a server-save attestation.

Protocol 8 and MAIN runtime V8 keep older extensions from accepting these new mode contracts. Reload the existing unpacked browser assistant after replacing its files. Permissions are unchanged.
