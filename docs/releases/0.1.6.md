# Mogao Content Studio 0.1.6 — connection recovery preview

Fix the browser handoff that could tell users to install an extension already present in the toolbar. The local page now stays on the same draft, reports the detected extension version, and offers recovery after a bounded wait. Background startup and navigation failures have explicit messages. A late extension response can still continue automatically.

The bundled browser assistant is 0.2.1. It reports presence before waiting for the service worker, acknowledges the current tab before navigating, and resumes the same draft from its toolbar button on both publish and legacy installation pages. Current tab ownership is rechecked, with duplicate launches and pages navigating away protected.

Update the three Obsidian plugin files while preserving `data.json`, then reload the plugin. Existing unpacked extension users must reload the updated extension once; if previously granted access was restricted, allow loopback and the destination platform. Normal publishing needs no file selection or additional import click.

Automated tests cover delayed responses, service worker timeout, navigation failure, retry, duplicate launch, legacy recovery, and origin/tab ownership checks. Full live platform acceptance is still pending. No final platform publication is performed, and this preview does not replace the current marketplace release.
