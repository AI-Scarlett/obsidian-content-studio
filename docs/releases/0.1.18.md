# Mogao Content Studio 0.1.18

修复通用模板采样和正文排版。六套内置模板现在分别定义字号、行距、段距、字距和缩进；预览、复制和浏览器投递共用完整的行内文字样式。

参考 GitHub 上的 obsidian-wechat-converter、doocs/md 和 wechat-style-extractor，接入 Juice CSS 内联引擎，支持 CSS 变量、结构选择器及字体简写。可识别的嵌套标题保留外框、内层色块和连续编号；避免将较小的图片说明当作主标题。参考文章图片继续跳过，保存的模板不包含原文或图片。

已有模板不会被自动覆盖。请重新采样来源链接并另存，以获得新的标题结构。需要验证的微信页面仍必须先由用户完成验证，图片内的标题装饰和复杂整篇布局不能保证还原。实现依据和验收边界见 [模板引擎研究](../template-engine-research.md)。

本版仅更新 Obsidian 插件，配套浏览器助手仍为 0.3.8。本次没有修改平台上传逻辑，也未执行最终发表。

验证：Obsidian lint、CSS lint、类型检查、122 项插件测试及 79 项浏览器助手测试通过。已在本机 Obsidian 1.13.7 加载 0.1.18，检查内置模板的实际正文排版，并通过采样弹窗验证 CSS 变量、嵌套色块和编号。更新前备份当前排版稿，更新后恢复原笔记及原模板选择；保存的模板未变。当前参考链接返回微信验证页，该链接本身的复刻效果仍未验收。
