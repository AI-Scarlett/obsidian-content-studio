Mogao Content Studio 0.1.2 addresses source, CSS and release review feedback while retaining automatic image loading and separate title/body copying.

- Sanitize HTML into DOM fragments; use Obsidian DOM/style helpers and CSS classes for fixed card geometry.
- Validate settings and DNS response types, use Obsidian requestUrl for DNS fallback, and add searchable settings definitions with support for older Obsidian versions.
- Use write-only Clipboard APIs and preserve user-triggered note selection; startup does not enumerate the Vault.
- Remove unsupported CSS font keywords and all !important declarations.
- Enforce the official Obsidian ESLint rules and CSS lint with zero warnings; 68 regression tests cover the affected behavior.

This release is built from its source tag by GitHub Actions. Artifact attestations cover all three files. Verify any downloaded file with `gh attestation verify <file> --repo AI-Scarlett/obsidian-content-studio`.

**Install/update:** place `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/content-studio/`. Preserve `data.json`, save your draft, and reload the plugin. Optional ZIP/checksum packages are available in Actions artifacts. Desktop only.

**Review boundary:** Vault Enumeration and Clipboard Access may remain as descriptions of necessary, user-triggered capabilities. Clipboard reading is not implemented. Community approval and actual platform paste/upload acceptance are separate from these source checks. The DOM refactor has automated coverage; native 0.1.2 visual validation is still pending.
