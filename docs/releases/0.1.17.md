# Mogao Content Studio 0.1.17 / browser assistant 0.3.8

修复知乎上传多图时的一处中断原因：编辑器重建已有图片节点后，旧版无法识别第二张新增图片，最终超时。现在按原生图片块与实体记录逐张核对，兼容重复图片和平台图片地址变化；放回原位置前确认图片属于本次上传，继续保留标题、正文和图片顺序检查。

更新已安装的浏览器助手文件后，在 Chrome 扩展管理页点击墨稿的“重新加载”，确认显示 **0.3.8**。仅更新 Obsidian 或刷新平台页面不会更新正在运行的助手。配套 Obsidian 插件为 **0.1.17**；协议升级为 10，旧助手不能领取新任务。完整安装说明见仓库 README 和 browser-extension/README.md。

本版保留 0.1.16 对“链接学模板”采样工具的通用修复；已有模板不会自动重写，重新采样后另存即可。参考文章的大图继续跳过，预览使用占位符。

Validation: two previously failing remount scenarios now preserve all three image positions, including duplicate image URLs and insertion beside a marker. Additional regressions cover CDN URL replacement, untrusted previews and stale upload bindings. These run against a real Draft.js model with a simulated uploader.
