# Mogao Content Studio 0.1.9 / browser assistant 0.3.2 preview

Live failure inspection found three distinct problems: Xiaohongshu retained a blob image with progress zero and all three markers; Zhihu retained only the initialization character and logged a React removeChild exception from DraftDriver.write; X rendered text but logged a Draft.js entity lookup error during autosave and had no body images. These are failed drafts, not successful delivery evidence.

The Draft.js driver now obtains character metadata from the platform's own ContentState constructor without inserting a seed into the DOM. Characters without links omit the entity field so Draft.js keeps its native null default. The previous explicit undefined value was treated as a missing entity key by serialization.

For Xiaohongshu PNG / JPEG images, the driver invokes the editor's configured native image-paste callback exactly once, supplying only the current image file. That callback uploads first, then inserts the returned platform URL. Public editor code shows that the toolbar starts asynchronous preview insertion without awaiting it before applying the upload result; an early upload result can therefore miss the image node. The new route avoids that race. No system clipboard access is added. Other formats retain the existing toolbar route and have not gained additional compatibility guarantees.

The tests now serialize Draft.js on every state change, round-trip saved documents including links and emoji, reject DOM seed writes, and exercise three native Xiaohongshu image-array blocks with upload results arriving before insertion. Upload failure still stops without claiming completion. These are offline contracts; the new route has not yet passed real-account upload, autosave and reopen acceptance.

Both components must update: the bridge requires protocol 5 and the progress page displays companion 0.3.2. No permissions are added. Install only the standard three Obsidian files and preserve data.json. Reload the existing unpacked companion once. No final publication is performed; this remains on the preview branch.
