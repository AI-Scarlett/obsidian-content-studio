# Mogao Content Studio 0.1.10 / browser assistant 0.3.3 preview

Clicking the browser assistant toolbar icon now requests opening Obsidian and the Mogao workbench through `obsidian://content-studio`. An existing workbench is revealed without replacing unsaved edits. A new workbench loads the active note, or opens empty if there is none. Startup waits for workspace restoration; repeated requests are coalesced. URI parameters cannot supply content or trigger publishing.

The browser retains the current platform/draft tab and opens a small launch page with an ordinary retry link. The browser or operating system may require external-app confirmation. Obsidian must be installed and Mogao enabled in the last-used vault. Clicking the toolbar on a pending localhost handoff still resumes that draft. No extension permissions are added; bridge protocol 5 and the existing publishing flow remain compatible.

Validation: 98 plugin tests and 48 browser assistant tests pass, along with source/CSS lint, both TypeScript checks, builds and the compiled package check. Regression coverage includes workspace restoration, preserving unsaved edits, no active note, repeated clicks, unload, ignored URI parameters, failed external navigation and unchanged publish handoff routing.

Local Obsidian 0.1.10 was enabled through native settings, and the newly opened workbench's title and complete Markdown match the pre-update snapshot with all 3 note images loaded. Plugin settings were preserved byte-for-byte. The 0.3.3 companion files are updated in the existing unpacked installation directory. Chrome reload and the actual toolbar-to-native-app wakeup are not yet verified. A direct browser URI-link attempt did not produce a confirmed native transition, so it is not counted as acceptance. Cold application startup is also unverified.

The prior platform image fixes still require live upload, autosave and reopen verification. This update does not claim those failures resolved. No final publication was performed; this remains a preview branch build.
