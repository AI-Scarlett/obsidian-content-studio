Mogao Content Studio 0.1.3 provides a larger writing workspace and explicit image delivery workflows.

- Write in a full-size editor, switch to preview, or compare side by side in a wide pane. Templates and style controls open in a drawer.
- Export WeChat DOCX with real embedded media in the original paragraph order. Use the platform's document importer and fill the title separately. Basic formatting is retained; template decorations and destination rendering can differ.
- Export Xiaohongshu cards or numbered original images for bulk upload, with separate title/body text and a folder shortcut. Cards preserve the arrangement of text and images as pixels.
- Correct image-copy messaging, relative font sizes in Word, and image decoding before card pagination.
- Keep source notes, custom templates, network protections and write-only clipboard behavior. No platform upload or automatic publishing is added.

Validation: official Obsidian ESLint and CSS checks with zero warnings, type checking, 74 tests and build/package checks. Browser validation covered 380/600/1100 px panes, a five-card PNG export, and a 15-page long-paragraph preview. A native DOCX containing PNG and WebP source media was exported through the UI, unpacked and rendered for visual review.

Platform acceptance and marketplace approval are separate gates. This release was not imported into the user's WeChat account or uploaded to Xiaohongshu during verification. Reload the installed plugin after preserving any temporary studio draft to use the new UI.
