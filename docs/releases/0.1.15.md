# Mogao Content Studio 0.1.15

修复“链接学模板”对大网页误报“内容过大”的问题。读取过程中跳过脚本、内嵌图片和媒体，仅保留样式提取所需的文档结构、文字与样式。参考文章图片不下载，模板预览中的图片使用占位符；原笔记和发布图片不变。

URL 与粘贴 HTML 使用同一精简流程。原始页面仍受 20 MB 上限约束，精简后的正文与样式受 3 MB 上限约束；保留超时、压缩、重定向和公网地址检查。重新提取成功时会清除上一次错误显示。

The reported WeChat page was 3,420,713 bytes, with 3,277,070 bytes of scripts and about 105 KB of article markup. The updated downloader reduced it to 120,128 bytes and extracted 21 style features; all three selected stylesheets were read successfully and no reference image request was made. Regression tests cover large scripts and embedded images, chunk boundaries, input/output limits, style preservation and placeholder image positions.

Verified in native Obsidian 1.13.7 with plugin 0.1.15 reloaded: the same link returned 21 style features, both preview images became placeholders, and saving the template was available. The existing draft and its two ordinary note images were preserved. All 107 plugin tests and 75 browser companion tests pass, with source/CSS lint, type checks and production builds.

Browser assistant 0.3.7 remains compatible and needs no reload for this Obsidian-only change. Existing platform upload validation boundaries remain unchanged; see [0.1.14](https://github.com/AI-Scarlett/obsidian-content-studio/blob/main/docs/releases/0.1.14.md).
