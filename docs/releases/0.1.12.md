# Mogao Content Studio 0.1.12 / browser assistant 0.3.5 preview

X previously moved each uploaded image once and immediately accepted the completed article. A later native editor update could move images to the end after that check. The adapter now retains the original paragraph and image positions, reconciles all uploaded media using their existing native blocks and media IDs, and checks for a stable layout for 2.5 seconds before reporting completion. Repeated movement restarts that interval, with a 15-second limit. No images are uploaded again.

Native insertion can split an image marker into a new block; the original marker text now identifies that position independently of the marker's current key. Exact restored markers are removed. Current paragraph text and media metadata are preserved, and cancellation, changed text, missing media or unexpected content stop reconciliation rather than overwriting the draft.

Protocol 7 and a new MAIN runtime prevent the previous adapter from handling new jobs. Update the Obsidian plugin and reload the existing unpacked browser assistant to 0.3.5. No new permissions or publication actions are introduced.

Validation: 98 plugin tests and 59 companion tests, lint, CSS lint, TypeScript, builds and packaging. New model regressions cover two images repeatedly moved to the end, with and without restored markers, native insertion at the marker, a later text edit, cancellation and document serialization. Uploads in these tests are simulated. Live read-only inspection of a freshly reopened saved X draft and its Preview showed two images at their source positions; the reported end-of-article placement was not reproduced in that saved copy. This patch does not establish complete real-account upload or server autosave acceptance. Browser-extension reload and upload-automation restrictions remain unresolved.
