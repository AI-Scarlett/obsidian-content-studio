# Mogao Content Studio 0.1.8 / browser assistant 0.3.1

Xiaohongshu long-form uses an atomic image block whose image and upload metadata are stored in `attrs.imgs[0]`. The previous adapter looked only at `attrs.src`. After the first native upload succeeded, its placement check therefore raised “小红书上传结果无法唯一对应到正文图片，已停止。” and the remaining images were never sent.

The adapter now recognizes the native image array and matches the exact rendered image to its document block. It moves that complete block, retaining dimensions, caption and upload completion metadata. Repeated uploads that receive the same URL still keep their separate positions.

The 0.1.8 plugin requires the new companion protocol before handing over any article, so a still-running 0.3.0 extension cannot silently use the broken adapter. The progress page displays the actual companion version. Update both components; reload the existing unpacked extension once. No new website permissions are added.

Two regressions use the observed atomic image-array structure, native insertion at the document selection, three uploads, both distinct and repeated URLs, and a JSON document save/reopen. They reproduced the first-image placement error before the fix and pass afterwards. The full suite passes 95 plugin tests and 43 companion tests, plus lint, CSS lint, TypeScript and builds.

The schema was verified against the currently loaded public Xiaohongshu editor bundle on 2026-09-09. Site JavaScript is kept only in ignored local research artifacts; it is not copied into this distribution. A separate native toolbar upload check was attempted with synthetic images, but the browser automation extension rejected file access. Extension management is also unavailable through the tool URL policy. Local model checks do not establish live end-to-end delivery or platform save/reopen acceptance. No final publication was performed.

Install only `main.js`, `manifest.json`, and `styles.css`, preserving `data.json`. The browser companion files are deployed to the existing unpacked extension directory. This remains a preview until real-platform acceptance.
