# Mogao Content Studio 0.1.5 — browser publishing preview

Mogao now starts browser delivery from **发布到公众号 / 发布到小红书 / 发布到知乎**. It captures the current draft, including unsaved edits and inline images, and opens the companion extension. The extension opens a fresh destination tab, waits for login, then sends the body, uploads images in place and fills the separate title. Missing extensions lead to installation onboarding with a bundled download. Routine article file selection and import steps have been removed.

Final platform publication remains manual. Existing drafts are preserved; failed uploads, changed image order or user edits stop further synchronization. X retains its copying and local export workflow.

This is a development preview. The extension's complete path on live Xiaohongshu, WeChat and Zhihu remains unverified; local integration tests and native image-paste baselines are separate evidence. See the browser extension README for exact limits.

Update only `main.js`, `manifest.json` and `styles.css`; keep `data.json`. Existing development users must reload the companion extension and accept the limited platform/local host permissions once. The extension ZIP is bundled inside the plugin for installation onboarding; no extra Obsidian release assets are needed.
